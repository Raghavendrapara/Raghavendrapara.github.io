The project

ImageJ is a public-domain Java image-processing program used widely in the life sciences. Active Segmentation is a redesign of ImageJ's Trainable Weka Segmentation (TWS). Its core was built during GSoC 2016 and it has been under active development since. It gives users a single interface for combining state-of-the-art image filters with machine-learning methods from the WEKA library, including active learning and multi-instance learning.

What I built (July – September 2020)

My summer was spent adding cell tracking to the plugin: following individual cells across the frames of a time-lapse image stack.

Training and annotation GUI

  • A tracking-training window showing the previous and next frames side by side, with frame-by-frame navigation.
  • Region-of-interest (ROI) selection with a smoothed wand tool, and labelling of ROIs against cell events (for example, apoptosis).
  • Saving and loading labelled ROIs (as zip archives) and event counters, so ground truth can be reused across sessions.

Tracking backend

  • A trellis graph built from the ROIs extracted in each frame, with node definitions for cells.
  • A Viterbi-based search over the trellis to link cells across frames, scored with an inverse-distance log-probability model for cell migration.
  • A tracking manager holding the event matrices (including apoptosis), plus a cell-displacement-variance measure.

Visualisation and hardening

  • Track overlays on the image, with the option to display tracks individually.
  • Fixes for canvas flicker, null-pointer exceptions and track colouring, followed by refactoring and documentation of the tracking code.
